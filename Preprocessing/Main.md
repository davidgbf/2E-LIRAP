# 🌍 Agricultural Packaging Waste Demand Estimation via ANN

This repository contains a predictive model based on **Artificial Neural Networks (Multilayer Perceptron - MLP)** developed in Python. The main objective of this script is to estimate the generation of agricultural packaging waste at the state level and perform a proportional downscaling to predict waste generation at the municipal level.

A key feature of this model is that it extracts the exact mathematical equation generated by the Neural Network, allowing the calculations to be easily replicated in Excel spreadsheets or integrated into external public/private management systems.

---

## ⚙️ How the Model Works (Pipeline)

The script is logically divided into 6 modules:

1. **Data Ingestion & Preprocessing:** Loads historical data, adjusts the target variable by assuming a historical collection rate of 94% (to estimate 100% of actual waste generation), and filters out statistical anomalies (e.g., the year 2020).
2. **Feature Scaling (Standardization):** Normalizes the input data (Mean = 0, Standard Deviation = 1) to ensure the Gradient Descent algorithm converges properly during MLP training.
3. **Training (Neural Network):** Trains the model using an architecture of 1 hidden layer with 3 neurons, **Hyperbolic Tangent (Tanh)** activation function, and the `lbfgs` optimizer.
4. **Statistical Evaluation:** Calculates and displays the model's performance metrics ($R^2$, MAE, RMSE).
5. **Mathematical Extraction:** Extracts and prints the network's Weights and Biases, formulating the complete algebraic equation ready for external application.
6. **Municipal Downscaling:** Uses the macro-scenario data to establish a **Dynamic Generation Factor (kg/ha)** and applies it to the individual planted area of each municipality.

## 📂 Required Inputs (Input Files)

For the script to execute successfully, the following two Excel files must be placed in the **same directory** as the Python script.

### 1. `Model_Waste.xlsx` (Training Data)
This spreadsheet contains the historical statewide and national series used to train the neural network. The first row must be the header. The script specifically looks for the following columns (kept in Portuguese to match your database):
* `Ano`: The year of observation (required to filter anomalies and find the most recent year).
* `Embalagens Brasil`: Total national packaging waste generated/collected (Feature X1).
* `Área Plantada Tocantins`: Total planted area of the target state in hectares (Feature X2).
* `Embalagens Tocantins`: Total packaging waste collected in the target state (Target Variable Y).

### 2. `Data_TO.xlsx` (Municipal Data for Downscaling)
This spreadsheet contains the list of municipalities and their respective planted areas for the target forecasting year. The first row must be the header. The columns must strictly follow this order:
* **Column A (1st):** Municipality Name (e.g., *Palmas*, *Araguaína*).
* **Column B (2nd):** Planted Area in the municipality (in hectares - numeric values only).

## 📊 Outputs (What the model delivers)

Upon completion, the script will provide:

1. **In the Terminal:**
   * Neural network validation metrics (R², MAE, RMSE).
   * The complete algebraic deduction of the Neural Network (Weights and Biases applied to the *Tanh* function).
   * The calculated Dynamic Generation Factor (kg/ha).

2. **Output File (`Data_TO_Calculated.xlsx`):**
   * A new spreadsheet will be automatically generated in the same folder. It will contain the two original municipal columns plus a **third column**: `Generated Waste (kg)`, which contains the final estimated waste in kilograms for each municipality, rounded to two decimal places.

## 🧠 Neural Network Architecture (MLP)

* **Input Layer:** 2 Features (National Waste, State Planted Area)
* **Hidden Layers:** 1 (containing 3 Neurons)
* **Activation Function:** Hyperbolic Tangent (`tanh`)
* **Optimizer:** `lbfgs` (Quasi-Newton method), highly recommended for small datasets.
* **Regularization (Alpha):** 0.01 (Applies L2 penalty to mitigate overfitting on short historical series).
